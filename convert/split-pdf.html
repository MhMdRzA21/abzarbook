Split a PDF

Pull a PDF apart into separate files — one per page, or by custom page ranges. Free, no account, no watermark.

Leave blank to split into one PDF per page. Or list ranges to split into custom chunks.

Drop a PDF here, or click to browse

Multiple output files download as a zip

.pdf

    How it works

    1. Add your PDF

    Drag and drop a PDF file, or click to browse and select it.

    2. Choose how to split

    Leave the ranges field blank for one file per page, or enter ranges for custom chunks.

    3. Download

    A single output downloads directly; multiple outputs download as a zip.

    Frequently asked questions

    What happens if I leave the page ranges field blank?

    The PDF is split into one file per page, and all of them are bundled into a single zip download.

    How do custom page ranges work?

    List ranges like "1-3, 5, 8-9" to get one PDF per range instead of one per page.

    Is my file kept after splitting?

    No — the uploaded PDF and the split files are deleted from the server right after you download the result.

    Extract pages without a desktop app

    Leave the range field blank to get one PDF per page, zipped. Or type ranges such as 1-3, 5, 8-9 to get one file per range. That is the usual way to send only the pages a client asked for, or to pull a form out of a longer pack.

    Splitting does not delete pages from the original on your computer; it builds new files. The source PDF can be up to 25MB. After you split, you can merge a subset back together, or compress a chunk that is still too large for email.
