Unlock a PDF

Remove the password from a PDF you already have access to, so you don't need to type it every time.

You need the correct password. This tool does not guess or break passwords.

Drop a PDF here, or click to browse

One file, up to 25MB

.pdf

    What happens to your file

    The file is opened with the password you give and saved again without encryption. The upload is deleted from the server right after you download the result.

    Questions

    Can you unlock a PDF if I forgot the password?

    No. The tool needs the correct password and doesn't try to crack anything.

    My PDF opens fine but won't let me edit or print. Will this help?

    Often yes. Leave the password box empty. If the file only has editing or printing limits, they are removed.

    Is it okay to unlock any PDF?

    Only unlock files you own or have permission to change.
