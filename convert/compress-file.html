      What "no quality loss" actually means here

      Images (JPG, PNG, GIF, TIFF): re-packaged with better, but still fully reversible, compression — every pixel comes back exactly as it went in.

      PDF: the file's internal object/stream container is recompressed more efficiently — no re-rendering of text or images.

      DOCX / XLSX / PPTX: these are ZIP files at heart; any embedded photos inside get losslessly recompressed and the whole package is re-zipped more tightly.

      Video: true bit-for-bit-lossless video barely shrinks at all, so "compress this video without quality loss" realistically means visually lossless — re-encoded at a high-quality setting where the difference isn't perceptible, even though it isn't a mathematically identical copy.

      Frequently asked questions

      Does compressing lose any quality?

      For images, PDFs and Office documents, no — pixel-for-pixel / byte-for-byte identical output. Video is re-encoded at a visually-lossless setting rather than being bit-for-bit identical (see above).

      Why didn't my file get smaller?

      If it was already efficiently compressed, there may be nothing left to save — you'll simply get your original file back rather than a larger one.

      What file types are supported?

      Images: JPG, PNG, GIF, TIFF. Documents: PDF, DOCX, XLSX, PPTX. Video: MP4, MOV, MKV, AVI, WEBM (video always comes back as MP4).

      Does it work on password-protected files?

      No — a password-protected PDF or Office file needs its password removed first (in the program that created it), since the tool can't open the file to compress it otherwise.

      Compress a PDF for email

      Most “PDF too large to email” problems are scanned pages or embedded photos, not the text. This compressor recompresses the PDF’s internal streams without re-rendering pages, so the document stays readable and pixel-identical. It will not invent a 1MB target if the file is already efficient — if nothing can be saved, you get the original back rather than a larger copy.

      Gmail’s attachment cap is 25MB. If a PDF is still over that after compression, split out the pages you actually need. Video is the only type here that is re-encoded instead of losslessly packed.
