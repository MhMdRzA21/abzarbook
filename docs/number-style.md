# قاعدهٔ نمایش عدد در ابزاربوک

1. **ابزارهای محاسباتی** (فیلدهای ورودی، placeholder، بخش «مثال محاسبه» و نتیجه‌ها): ارقام **لاتین** با جداکننده سه‌رقمی برای مبلغ، مثل `700,000` و `1,000,000,000`.
2. **سال‌ها** مثل `1405` بدون کاما نوشته شوند.
3. **عنوان‌ها، متن‌های توضیحی و تاریخ‌های فارسی** همچنان با ارقام فارسی نوشته می‌شوند (مثلاً «۱۴۰۵»).
4. **شماره‌های شناسه** (شبا، کد ملی، شماره تماس) بدون جداکننده نوشته می‌شوند.
5. ورودی‌های پولی باید با `AB.liveFormat` (فایل `assets/num-fa.js`) فرمت شوند و مقدارشان قبل از محاسبه با حذف کاما خوانده شود.
