# ابزاربوک (abzarbook.ir)

ابزارهای آنلاین کاملاً رایگان فارسی برای محاسبات مالی، متنی و کاربردی.

## دامنه
سایت روی دامنه **abzarbook.ir** فعال است.

## کانال تلگرام
[@abzarbook](https://t.me/abzarbook)

## دیپلوی روی Railway

1. این پوشه را به یک ریپازیتوری گیت‌هاب پوش کنید (ریشه ریپو باید همین فایل‌ها باشد).
2. در Railway: New Project → Deploy from GitHub repo → همین ریپو را انتخاب کنید.
3. Railway به‌خاطر وجود `package.json` به‌صورت خودکار Node را تشخیص می‌دهد و با `npm start` سرور را بالا می‌آورد (پورت از متغیر محیطی `PORT`).
4. بعد از دیپلوی موفق، دامنه سفارشی `abzarbook.ir` را وصل کنید.

## ساختار فایل‌ها

- `index.html` — صفحه اصلی (هاب ابزارها)
- `hoghoogh-dastmazd.html` — عیدی، سنوات و مالیات حقوق ۱۴۰۵
- `rahn-vam.html` — رهن به اجاره + وام ازدواج و فرزندآوری
- `text-tools.html` — ابزار متن فارسی (کیبورد، نیم‌فاصله، عدد به حروف)
- `vahed.html` — مبدل واحد
- `salamat.html` — محاسبه‌گر سلامت (BMI، کالری، آب بدن)
- `size-chart.html` — مبدل سایز پوشاک و کفش
- `etebarsanji.html` — اعتبارسنجی شبا و کد ملی
- `taghvim.html` — تقویم و تبدیل تاریخ
- `sen.html` — محاسبه سن
- `qrcode.html` — ساخت کد QR
- `ramz.html` — رمزساز
- `server.js` — سرور استاتیک ساده
- `robots.txt`, `sitemap.xml` — سئو
- `manifest.json`, `sw.js` — پشتیبانی PWA (اختیاری)

همه محاسبات در مرورگر کاربر انجام می‌شود. هیچ داده‌ای ارسال یا ذخیره نمی‌شود.

## رقبای اصلی و مزیت رقابتی ابزاربوک

| رقیب | ضعف اصلی | برتری ابزاربوک |
|------|----------|----------------|
| kitset.ir | طراحی قدیمی، سرعت متوسط | UI مدرن‌تر + سرعت بالاتر + تمرکز قانونی دقیق‌تر |
| tools.negareno.com | پراکندگی زیاد ابزارها | تمرکز عمیق روی ابزارهای مالی/حقوقی پرترافیک ایران |
| 100kit.ir / toolschi.com | عمق کم در محاسبات قانونی | دقت مصوبات ۱۴۰۵ + Schema قوی |
| حسابچی / پیشخوانک / آریاکیت | تک‌ابزاری یا محدود | مجموعه کامل + جستجو + UX یکپارچه |
| رازگشا / تولیوم | کلی و غیرتخصصی | تخصص ایران‌محور + حریم خصوصی مطلق |

### مزایای کلیدی برای جذب ترافیک و آماده‌سازی تبلیغات:
- **سرعت بالا** (gzip + cache هوشمند + zero-dependency)
- **سئوی سنگین** (FAQ + HowTo + ItemList + WebSite schema)
- **جستجوی داخلی** ابزارها
- **حریم خصوصی مطلق** (هیچ دیتایی ارسال نمی‌شود) → اعتماد بالاتر
- **تمرکز روی کلمات کلیدی پرترافیک**: عیدی ۱۴۰۵، سنوات، رهن به اجاره، وام ازدواج
- آماده برای قرار دادن تبلیغات (صفحات تمیز، سرعت بالا، UX خوب)
